# PipOS Android

Первый Android-модуль проекта PipOS — приложение-конфигуратор оформления.

## Стек
- Kotlin
- Jetpack Compose
- Material 3
- Minimum Android SDK: 26

## Сборка
Открой папку `android-app/` в Android Studio и дождись синхронизации Gradle. Для сборки APK используй **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Также добавлен GitHub Actions workflow: он собирает debug APK при изменениях в `android-app/` на ветке `android-customizer`. Готовый APK публикуется как artifact запуска workflow.

## Резервная копия
Раздел **Резервная копия** умеет экспортировать и импортировать ZIP-пакет PipOS через системный выбор файлов Android.

Структура пакета:
- `manifest.json` — формат и версия пакета;
- `settings.json` — настройки темы, акцентного цвета, шрифта и набора иконок.

Импорт проверяет формат и размер файла настроек. Текущая версия переносит именно настройки приложения; сами файлы шрифтов, иконок и обоев будут добавлены в пакет на следующих этапах.

## Текущий статус
Версия 0.2.0 — стартовый интерфейс и рабочий прототип ZIP-резервного копирования. Разделы системных тем, шрифтов и иконок пока не применяют изменения ко всей ОС: доступность таких функций зависит от прошивки и производителя устройства.
