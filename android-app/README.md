# PipOS Android

Первый Android-модуль PipOS — приложение-конфигуратор и экспериментальный домашний экран Android.

## Стек
- Kotlin
- Jetpack Compose
- Material 3
- Minimum Android SDK: 26

## Сборка
Открой папку `android-app/` в Android Studio или используй GitHub Actions workflow. Готовый debug APK публикуется как artifact запуска workflow.

## Уже работает
- Чёрно-фиолетовый интерфейс PipOS.
- Выбор одной из шести акцентных цветовых тем.
- Сохранение выбранной темы.
- Экспорт и импорт настроек через ZIP.
- Автоматические тематические иконки приложений внутри PipOS Launcher: исходные значки стилизуются в чёрно-фиолетовой палитре, AI-приложения получают корону.
- Первый вариант PipOS Launcher: отдельная домашняя активность Android, список запускаемых приложений, поиск и запуск приложений.
- Android предлагает выбрать PipOS как приложение главного экрана; после выбора кнопка Home открывает PipOS.

## Важно
Лаунчер меняет рабочий стол, который он сам отображает. Он не заменяет значки в системных настройках, уведомлениях и других экранах Android. Чтобы использовать PipOS, выбери его в системном диалоге выбора приложения «Главный экран» / Home app. Старый лаунчер остаётся установленным, и к нему можно вернуться через настройки Android.

Лаунчер автоматически получает значки установленных приложений из Android, стилизует их в чёрно-фиолетовой палитре и обновляет список при каждом возвращении на рабочий стол. Для распознанных AI-приложений добавляется корона. Значки меняются только внутри PipOS Launcher; системные экраны Android не затрагиваются.
