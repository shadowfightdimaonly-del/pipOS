# PipOS Android

Первый Android-модуль проекта PipOS — приложение-конфигуратор оформления.

## Стек
- Kotlin
- Jetpack Compose
- Material 3
- Minimum Android SDK: 26

## Сборка
Открой папку `android-app/` в Android Studio и дождись синхронизации Gradle. Для сборки APK используй **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Также добавлен GitHub Actions workflow: он собирает debug APK при изменениях в `android-app/` на ветке `android-customizer`. Готовый APK публикуется как artifact запуска workflow.

## Уже работает
- Стартовый экран PipOS в чёрно-фиолетовом оформлении.
- Выбор одной из шести акцентных цветовых тем.
- Сохранение выбранной темы в настройках приложения.
- Экспорт и импорт настроек через ZIP-файл Android Storage Access Framework.\n- Выбор установленного приложения, импорт изображения и создание отдельного закреплённого ярлыка с пользовательской иконкой (Android 8+; зависит от поддержки лаунчера).

## Резервная копия
Структура пакета:
- `manifest.json` — формат, версия пакета и дата создания;
- `settings.json` — настройки темы, акцентного цвета, шрифта и набора иконок.

Импорт проверяет наличие и корректность файла настроек, а также ограничивает его размер. Сейчас переносит настройки приложения; сами файлы шрифтов, иконок и обоев будут добавлены позднее.

## Ограничения и следующие этапы
PipOS — приложение для кастомизации, а не прошивка и не замена Android. Обычное приложение не может универсально менять системные шрифты, значки всех приложений или интерфейс любой оболочки. Это зависит от лаунчера, версии Android и производителя устройства.

Следующие этапы:
- выбор и применение обоев рабочего стола через системный выбор изображений;
- импорт пользовательских шрифтов для предпросмотра внутри PipOS;
- расширенный каталог иконок и совместимость с поддерживаемыми лаунчерами;
- коллекции оформления и перенос ресурсов в ZIP.
