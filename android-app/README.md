# PipOS Android

Первый Android-модуль проекта PipOS — приложение-конфигуратор оформления.

## Стек
- Kotlin
- Jetpack Compose
- Material 3
- Minimum Android SDK: 26

## Сборка
Открой папку `android-app/` в Android Studio и дождись синхронизации Gradle. Для сборки APK используй **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Текущий статус
Версия 0.1.0 — стартовый интерфейс. Разделы пока демонстрационные: реальные операции с системными темами, шрифтами и иконками будут добавляться отдельно с учётом ограничений конкретных прошивок.
