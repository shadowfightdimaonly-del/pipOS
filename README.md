# PipOS

Экспериментальная операционная система.

## Архитектура

- `boot/` — загрузка системы
- `kernel/` — ядро
- `drivers/` — драйверы устройств
- `lib/` — базовые библиотеки
- `user/` — пользовательское пространство
- `tools/` — инструменты сборки и разработки
- `docs/` — документация

Пока это каркас проекта. Никакого магического «удаляем Android и готово» пока нет. К счастью для телефона.
