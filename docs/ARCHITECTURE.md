# Архитектура PipOS

## Слои

1. Bootloader — запускает ядро.
2. Kernel — память, процессы, прерывания и базовое управление CPU.
3. Drivers — связь ядра с железом.
4. Runtime/Lib — базовые функции для программ.
5. User space — приложения и оболочка.

## Принцип

Сначала добиваемся загрузки минимального ядра в эмуляторе. Реальное устройство рассматривается только после появления рабочего прототипа и понимания его boot chain.
